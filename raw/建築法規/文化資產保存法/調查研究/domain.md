# 調查研究

## 使用情境
本技能適用於文化資產修復工程的前置階段。依據《文化資產保存法》，在進行實質修復設計前，必須先進行歷史考證、現場測繪及現況損壞調查，產出調查研究報告書。

## 學習目標
- 掌握文化資產修復前期的法令規定與作業流程。
- 熟悉現場損壞調查的紀錄順序（由上而下、由大至小）。
- 了解非破壞性檢測（NDT）與現代測量技術的應用。

## 實務與應用

進行調查研究時，應包含以下關鍵項目：

- **文獻與歷史考證**：梳理該建築之興建背景、歷年增改建脈絡，確立其歷史價值。
- **都市計畫與環境調查**：檢討基地之主要計畫與細部計畫，包含建蔽率、容積率及土地使用分區。若位於「保存區」，必須嚴格遵守上位保存計畫之規定。
- **現代測量技術（現場測繪）**：多數文化資產（如清代、日治時期或建築法實施前之建物）並無原始建造執照圖說。目前的現場測繪已不再侷限於傳統的雷射測距儀，實務上強烈建議導入 **360度全景相機**、**雷射點雲掃描 (3D Point Cloud Scanning)** 及 **無人機空拍 (UAV)** 等新式測量技術，以建立極具精確度的現況測繪圖（平面、立面、剖面圖及大樣詳圖）。
- **現況損壞文字紀錄**：現場損壞狀況的文字敘述，必須嚴格遵循邏輯順序：「**屋頂 -> 結構體 -> 天花板 -> 牆面 -> 地坪 -> 樓梯 -> 門窗 -> 裝飾構件**」。發現的損壞現象應與歷史工法交叉比對。
- **非破壞性檢測 (NDT)**：因文化資產具不可替代性，結構調查應以非破壞性檢測為主。例如 RC 及加強磚造可進行混凝土鑽心、鋼筋掃描，並配合初步耐震評估 (PSERCB)；木構造則需運用特有之非破壞檢測儀器與木構造運算。
- **修復建議**：為後續的修復設計階段提出初步的準則與方向。
